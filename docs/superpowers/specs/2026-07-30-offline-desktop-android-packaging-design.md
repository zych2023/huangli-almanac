# 黄历速查 Windows 与安卓离线封装设计

## 目标

在不依赖 HTTPS 地址、服务器或应用商店的前提下，将现有黄历速查 PWA 封装为可本地安装的 Windows 应用和安卓 APK。两端复用同一套页面、黄历算法与设置逻辑，首次启动即可完全离线使用。

## 交付范围

- Windows 10/11 64 位安装程序，用户级安装，不要求管理员权限。
- 供本人和家人侧载的通用安卓 APK。
- 安卓固定签名文件及其恢复说明，用于后续覆盖升级。
- 简短安装、卸载和升级说明。
- 不发布公网地址，不接入应用商店，不实现联网自动更新。

## 技术方案

### 共享 Web 应用

现有 Preact 应用仍是唯一的业务实现。生产构建生成的静态资源包含页面、`lunar-javascript`、事项词表、图标和样式。桌面与安卓壳只负责加载这些内置资源，不复制黄历计算逻辑。

PWA 清单和 Service Worker 保留，继续服务未来可能的网页发布；原生壳内的离线能力来自安装包内置资源，不依赖 Service Worker 是否生效。

### Windows

采用 Tauri 2 封装现有生产构建，使用 Windows 自带的 WebView2 渲染。目标为 Windows 10/11 x64，输出用户可双击运行的安装程序。固定应用标识与数据目录，以便新版安装程序覆盖升级时保留本地设置。

Tauri 相比 Electron 不附带完整 Chromium，预期安装包约 5-15 MB，启动和内存占用也更低。实际体积以最终构建产物为准。现代 Windows 10/11 通常已安装 WebView2；缺失时安装流程必须给出明确提示，不允许只出现空白窗口。

### 安卓

采用 Capacitor 封装同一份生产构建，使用系统 Android WebView 渲染。输出一个便于家庭设备安装的通用 APK，不申请联网、定位、通讯录、相机等业务不需要的权限。

APK 使用固定包名和本地长期签名。签名文件不打入 APK，也不放入公开产物目录；需与密码恢复说明一起备份。后续版本必须使用同一签名，才能覆盖安装并保留应用数据。预期 APK 约 4-10 MB、安装后约 15-30 MB，实际体积以最终构建产物为准。

## 数据与更新

- 自定义快捷入口、时区等设置继续保存在各设备本地存储中。
- 手机和电脑之间不自动同步数据。
- 两端均不检查网络更新；用户通过新版安装包手动覆盖升级。
- 固定应用标识、安卓包名和签名，确保正常覆盖升级时保留本地设置。
- 卸载应用可能清除本地设置，安装说明需明确说明这一点。

## 构建环境

当前机器已有 Node.js，但缺少 Rust、JDK、Android SDK/NDK 和相关原生构建工具。实施阶段需要安装并固定可复现的构建版本：

- Windows：Rust、Tauri CLI 及 Windows 原生构建依赖。
- 安卓：JDK、Android SDK、Android 构建工具，以及 Capacitor 所需依赖。

这些工具只用于生成安装包，最终用户无需安装。

## 失败处理

- Windows 缺少 WebView2：安装或启动时显示可操作的安装提示。
- 安卓 WebView 版本过旧：启动失败时提供更新 Android System WebView 的说明。
- 安卓签名缺失或不匹配：构建流程应在产物生成前失败，不能生成无法升级的正式交付包。
- 静态资源缺失：Windows 与安卓构建都必须依赖一次成功的 Web 生产构建，禁止封装旧的或不完整的 `dist`。

## 验收标准

### 共享功能

- 断网状态可冷启动并进入首页。
- 今日宜忌、日期详情、前后日期导航正常。
- 所有标准事项及日常别名可搜索。
- 宜/忌模式切换及其严格筛选规则与网页版本一致。
- 五个自定义快捷入口可保存、恢复默认，并在重启后保留。

### Windows

- 在 Windows 10/11 x64 完成安装、启动、关闭和卸载。
- 普通用户安装不需要管理员权限。
- 覆盖安装新版后本地设置仍存在。
- WebView2 缺失时不出现无提示的空白窗口。

### 安卓

- 在实体安卓手机完成允许未知来源、安装、启动和卸载。
- 开启飞行模式后仍可完成主要查询流程。
- APK 不声明不必要的敏感权限。
- 使用同一签名覆盖安装新版后本地设置仍存在。

### 产物

- 记录 Windows 安装包和 APK 的实际文件大小及 SHA-256。
- 安装说明列出文件名、适用系统、安装步骤、升级方式和卸载影响。
- 安卓签名备份不与公开安装包混放。

## 非目标

- iPhone/iPad 安装包。
- Microsoft Store、Google Play 或其他应用商店发布。
- 公网托管、账号系统、跨设备同步和云备份。
- 后台常驻、通知推送与自动更新服务。
