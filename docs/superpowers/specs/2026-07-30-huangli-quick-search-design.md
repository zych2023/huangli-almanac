# 黄历宜忌速查工具设计

## 目标

构建一个可在电脑和手机上安装的轻量黄历工具，用于快速查看当天宜忌，以及查询某件事在未来一段时间内严格适宜的日期。应用公开可用，不要求登录或跨设备同步。

核心目标：

- 常见 4G 网络下首次可用时间不超过 2 秒。
- 安装后离线启动目标不超过 0.5 秒。
- 宜忌结果口径固定、可追溯、可复现。
- 用户可用“搬家”“结婚”等日常说法查询，无需掌握黄历术语。

## 产品范围

第一版包含：

- 首页事项搜索和常用事项快捷入口。
- 默认查询未来 90 天，也可自选日期范围。
- 当天宜忌摘要。
- 日期详情：公历、农历、星期、宜、忌。
- 日期前后切换。
- 默认北京时间，可切换为设备时区。
- PWA 安装和完整离线使用。

第一版不包含：

- 账户、登录、跨设备同步。
- 冲煞、彭祖百忌、吉神凶煞、方位、十二值星等扩展字段。
- 多来源结果融合或在线黄历 API。
- 个性化择日、生辰八字或结果推荐排序。

## 数据口径

唯一宜忌来源为 `6tail/lunar-javascript v1.7.7`，在依赖中锁定精确版本。所有计算在浏览器本地完成，不依赖在线接口。设置或关于区域明确展示数据源、版本和民俗参考说明。

版本升级必须作为显式数据口径变更处理：升级前用固定样本集比较结果，不自动跟随上游最新版本。

## 查询规则

搜索词先通过本地同义词表映射为一个或多个黄历术语，例如：

- 结婚 -> 嫁娶
- 搬家 -> 入宅、移徙
- 开业 -> 开市
- 装修 -> 修造

界面始终显示实际匹配的黄历术语，保证结果可解释。

对日期范围内的每一天进行严格判断：目标术语必须出现在当日“宜”列表，并且不能出现在“忌”列表，才视为符合。若一个日常事项映射到多个术语，任一术语满足严格条件即可入选，同时记录具体命中的术语。未被提及的日期不视为适宜。

结果按日期由近到远排序。范围内没有符合日期时，明确显示“所选范围内没有严格符合的日期”，不降低判定标准。

## 页面与交互

首页采用“事项搜索优先”布局：

1. 顶栏显示产品名、当前时区和设置入口。
2. 首屏主操作为事项搜索框。
3. 搜索框下方显示常用事项快捷入口。
4. 搜索后显示匹配术语、日期范围和结果列表。
5. 首页下半部分保留当天宜忌摘要。

搜索支持常用词建议和明确的无结果状态。点击结果进入日期详情。详情页只展示第一版需要的信息，并提供前一天、后一天和返回操作。

设置只提供两个时区选项：北京时间和设备时区。时区只决定“今天”的日期边界；指定公历日期的黄历内容不因时区改变。选择保存在本机。

## 技术架构

采用纯静态 PWA。界面、同义词表、黄历计算库和应用图标均随版本发布，由 Service Worker 缓存。应用不需要后端、数据库或 API Key。

内部模块按职责拆分：

- 黄历适配层：封装第三方库，输出稳定的应用数据结构。
- 事项词典：规范化输入并返回对应术语。
- 日期搜索服务：遍历范围并执行严格宜忌判定。
- 时区服务：计算北京时间或设备时区下的“今天”。
- 页面组件：首页、结果列表、日期详情和设置。
- 离线层：应用清单、缓存策略和版本更新提示。

搜索计算量按天数线性增长。默认 90 天规模很小，可在主线程即时完成；同时限制自选范围，避免异常大的查询阻塞界面。

## 性能与离线

- 首屏只加载首页所需代码和样式，避免大型 UI 框架和非必要资源。
- 生产资源压缩、拆包，并为长期缓存生成内容哈希。
- 首次成功访问后缓存完整核心应用，后续可完全离线启动和查询。
- Service Worker 更新在后台完成，检测到新版本后提示用户刷新，不在使用中强制替换。
- 验收时分别测量首次加载、二次加载和离线启动。

## 错误处理

- 不支持的搜索词：提供可用术语建议，不猜测结果。
- 无严格符合日期：展示明确空状态，并允许扩大日期范围。
- 日期范围无效或过大：在提交前校验并给出具体修正提示。
- 本地计算异常：显示当前日期无法计算，并保留重试和返回能力。
- 缓存更新失败：继续使用已缓存版本，不影响离线查询。

## 测试与验收

- 单元测试：同义词映射、严格宜忌判定、日期范围边界和时区日期边界。
- 适配层契约测试：锁定一组日期的公历、农历、宜、忌输出，防止依赖升级造成静默变化。
- 搜索测试：常用事项、多个映射术语、无结果和自选范围。
- PWA 测试：安装清单、Service Worker 更新、断网重载和离线查询。
- 响应式测试：主流手机宽度和桌面宽度下无溢出、遮挡或不可操作控件。
- 性能测试：常见 4G 条件首次可用目标不超过 2 秒；已安装或已缓存离线启动目标不超过 0.5 秒。

## 发布说明

应用公开部署为静态站点。页面明确说明黄历宜忌属于传统民俗信息，仅供参考；同时展示 `lunar-javascript v1.7.7` 作为当前固定数据口径。
