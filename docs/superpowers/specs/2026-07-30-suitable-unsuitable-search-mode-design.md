# 宜日与忌日搜索模式设计

## 目标

用户可以从左上角快速在“宜日查询”和“忌日查询”之间切换。切换仅影响首页未来日期搜索，不改变今日宜忌、日期详情、快捷入口或设置。

## 顶栏交互

左上角现有品牌区拆成两个相邻控件：

- 方形印章显示当前模式“宜”或“忌”，点击切换模式，提供明确的无障碍名称“切换为忌日查询”或“切换为宜日查询”。
- “黄历速查 / 宜忌 · 择日”文字继续作为返回首页按钮。

默认模式为“宜”。模式只保留当前会话状态，不写入本地存储。进入日期详情再返回时保持当前模式。

## 搜索规则

宜日模式沿用现有严格规则：目标术语出现在当日“宜”，且不出现在当日“忌”。

忌日模式使用对称严格规则：目标术语出现在当日“忌”，且不出现在当日“宜”。

同一日若目标事项映射的任一术语满足当前规则，该日进入结果，并记录实际命中的术语。日期范围校验、排序和无效事项处理保持不变。

## 页面文案

宜日模式：

- “最近哪天适合？”
- “查找明确记为‘宜’的日期”
- “适合的日期”
- 结果标签“宜 ××”

忌日模式：

- “最近哪天不宜？”
- “查找明确记为‘忌’的日期”
- “不宜的日期”
- 结果标签“忌 ××”

无结果状态随模式显示“没有严格符合的宜日”或“没有严格符合的忌日”，判定标准不自动降低。

## 状态切换

搜索模式由 `App` 持有并传入首页。若首页已经显示某事项的查询结果，切换模式后立即使用原事项和原日期范围重新计算；若尚未查询，只更新界面文案。

今日宜忌区域保持原有“宜”在前、“忌”在后的展示，不随搜索模式改变。

## 测试与验收

- 默认显示宜日模式，现有搜索结果不回归。
- 点击左上角印章切换为忌日模式，再次点击恢复宜日模式。
- 宜日与忌日筛选分别执行对称的严格排除规则。
- 已有查询在切换模式后自动重新计算。
- 忌日模式的标题、说明、结果标题、结果标签和空状态文案正确。
- 日期详情返回后保持模式与查询结果。
- 顶栏在桌面和 375px 手机宽度无溢出，两个控件均可键盘操作。
